## Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Runs `next dev` |
| `npm run build` | Runs `prisma generate && next build` |
| `npm run postinstall` | Runs `prisma generate` |
| `npm run start` | Runs `next start` |
| `npm run lint` | Runs `next lint` |
| `npm run typecheck` | Runs `tsc --noEmit` |
| `npm run test` | Runs `vitest run` |
| `npm run test:watch` | Runs `vitest` |
| `npm run test:coverage` | Runs `vitest run --coverage` |
| `npm run test:e2e` | Runs `playwright test` |
| `npm run prisma:generate` | Runs `prisma generate` |
| `npm run prisma:format` | Runs `prisma format` |
| `npm run supabase:gen-types` | Runs `supabase gen types typescript --local > src/infrastructure/persistence/supabase/database.types.ts` |
| `npm run doctor` | Runs `npx react-doctor@latest` |
