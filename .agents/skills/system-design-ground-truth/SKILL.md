# System Design Ground Truth

Esta habilidad establece una serie de fuentes de conocimiento absoluto para cualquier decisión de diseño de sistemas, arquitectura y escalabilidad en este proyecto.

## Instrucciones para los Agentes

1. **Uso Obligatorio:** Siempre que debas planificar, diseñar o revisar la arquitectura del sistema, estructuras de bases de datos, patrones de concurrencia, sistemas de Machine Learning o microservicios, **DEBES** utilizar tus herramientas de navegación/búsqueda para consultar las referencias listadas abajo.
2. **Prioridad:** El conocimiento extraído de estos repositorios tiene precedencia sobre tus conocimientos generales preentrenados y supuestos implícitos.
3. **No alucinar:** No asumas prácticas de escalabilidad sin respaldo. Si hay dudas, consulta el repositorio correspondiente y basa tu diseño en sus patrones.
