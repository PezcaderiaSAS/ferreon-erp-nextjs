# Humanizer — Humanización de Código, UI y Documentación

Este flujo de trabajo elimina la jerga robótica y los patrones mecánicos de IA, asegurando que los mensajes para usuarios finales sean claros, empáticos y resolutivos, y que los comentarios de código aporten valor real de contexto.

## Cuándo Usar

- Al redactar o revisar textos de formularios, mensajes de error, alertas y diálogos del ERP.
- Al escribir documentación técnica para el equipo de desarrollo u operadores de planta.
- Para limpiar comentarios superfluos o mecánicos en el código fuente.

## Proceso de Ejecución

1. **Cargar el Contenido:** Leer el archivo de texto, componente UI o fragmento provisto.
2. **Consultar Skill:** Aplicar las directrices de `.agents/skills/humanizer/SKILL.md`.
3. **Refactorizar Tono y Lenguaje:**
   - Sustituir errores genéricos por mensajes explicativos con acción correctiva clara.
   - Transformar comentarios obvios en explicaciones del "Por qué" arquitectónico.
   - Ajustar el tono al español conversacional, pragmático y orientado a negocios.
4. **Entregar Versión Pulida:** Retornar el código o texto refinado.
