# Styleguide — Referencia de Sistemas de Diseño de Producción (streamich/awesome-styleguides)

Inspirado en [streamich/awesome-styleguides](https://github.com/streamich/awesome-styleguides), este flujo de trabajo proporciona acceso a los patrones de interacción y arquitectura de componentes probados en producción por las mayores empresas tecnológicas.

## Cuándo Usar

- Al concebir componentes complejos (tablas de datos interactivas, wizards multi-paso, menús contextuales).
- Para comparar cómo resuelven problemas de ergonomía y accesibilidad librerías como Radix UI o Shopify Polaris.
- Para evitar reinventar patrones de interacción ya consolidados en la industria.

## Proceso de Ejecución

1. **Identificar el Componente:** Determinar el tipo de interacción o interfaz a diseñar.
2. **Consultar Skill:** Aplicar los patrones de `.agents/skills/ui-ux-ecosystem/SKILL.md`.
3. **Mapear Solución de Referencia:**
   - **Tablas de datos complejas:** Referencia Shopify Polaris / GitHub Primer.
   - **Primitivas accesibles y focus management:** Referencia Radix UI.
   - **Jerarquía y paneles laterales:** Referencia Microsoft Fluent.
4. **Sintetizar Componente:** Implementar el componente adaptado a las necesidades de FerreOn / AppFrios Pezca.
