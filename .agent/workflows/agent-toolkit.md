# Agent Toolkit — Centro de Mando del Ecosistema Integrado

Este flujo de trabajo ofrece un resumen operativo y guía rápida de todos los comandos slash y herramientas especializadas disponibles en el proyecto FerreOn / AppFrios Pezca.

## Directorio de Comandos Slash Disponibles

### 🛠️ Herramientas de Ingeniería y Agentes
- `/archify`: Modelado y diagramación de arquitectura de software C4 en Mermaid.
- `/scientific-skills`: Validación matemática de algoritmos, rigor numérico y precisión de punto flotante.
- `/agent-skills`: Auditoría de calidad web (Web Vitals, UX engineering, Clean Code) de Addy Osmani.
- `/open-design`: Extracción, normalización e interoperabilidad de componentes de diseño a código.
- `/ponytail`: Tailoring dinámico de prompts y optimización de contexto para agentes.
- `/humanizer`: Pulido y humanización de mensajes de UI, comentarios y documentación técnica.

### 🎨 Ecosistema UI/UX y Sistemas de Diseño
- `/design-md`: Gestión y auditoría de tokens de diseño (`DESIGN.md`).
- `/ui-tools`: Generador de utilidades CSS avanzadas (sombras multinivel, glassmorphism, gradientes).
- `/styleguide`: Catálogo de referencias de Design Systems en producción (Polaris, Primer, Radix).
- `/penpot`: Pautas de diseño, prototipado web abierto y layouts vectoriales.

## Modos de Invocación
- Ejecutar cualquier comando directamente anteponiendo `/` seguido de los argumentos (ej. `/archify backend/services/InvoiceService.js`).
- Consultar la documentación detallada de cada habilidad en `.agents/skills/<nombre_herramienta>/SKILL.md`.
